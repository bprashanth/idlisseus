# s2 — Sentinel-2 10 m canopy/greenness detail (Earth Engine, free)

- **produces:** `at(points)` → +`ndvi_10m` + `cover_10m` (dense canopy / sparse-scrub / bare);
  `summary(bbox)` → `mean_ndvi_10m` + `pct_dense_canopy`. Cloud-masked seasonal median, 10 m.
- **why:** WorldCover gives broad CLASSES, MODIS greenness is ~250 m, AlphaEarth is opaque. When you
  need canopy DENSITY / bare-vs-vegetated / fine dry-season structure, raw Sentinel-2 is the tool —
  and it's FREE (COPERNICUS/S2_SR_HARMONIZED). Use it instead of only *suggesting* higher-res imagery.

**functions**
- `at(points, year=2023) -> +ndvi_10m, +cover_10m`
- `summary(bbox, year=2023) -> mean_ndvi_10m, pct_dense_canopy`
- `anomaly(bbox, year=2024) -> dry-season STAY-GREEN summary` (invasive-likelihood)
- `anomaly_at(points, year=2024) -> +ndvi_wet, +ndvi_dry, +retain, +stay_green(0/1), +worldcover`
- `anomaly_grid(bbox, year=2024, n=30) -> n×n grid of the anomaly fields` (raw material for a map)

**the phenology anomaly (invasive-likelihood):** native dry-deciduous forest DROPS its leaves in the
dry season (NDVI falls); Lantana and other evergreen invaders STAY GREEN. A cell that is vegetated in
the wet flush (Dec–Feb) AND retains greenness through the dry season (Mar–Jun), on natural land
(crop/built/water masked via WorldCover), is an invasive CANDIDATE. This is the free first stage of the
"where is the lantana" funnel → confirm with `embedding` similarity to known presence + `occurrence`
(see PLAYBOOK "where are the invasives"). `invasive_map.py` runs the whole funnel to an HTML map.

**example**
```
python /opt/data/connectors/s2.py summary --bbox 78.170,12.721,78.197,12.747
python /opt/data/connectors/s2.py anomaly --bbox 78.170,12.721,78.197,12.747       # invasive-likelihood %
python /opt/data/connectors/s2.py anomaly_grid --bbox 78.170,12.721,78.197,12.747 --n 28 --out grid.csv
```

**gotchas:** 10 m NDVI is a canopy-density PROXY, **not species ID** (species needs hyperspectral —
EMIT/Pixxel). Cloud-masked median; sparse-data/dry seasons can be noisy. Pair with `greenness` (trend
over time), `landcover` (class), `terrain`.
