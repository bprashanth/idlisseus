This dataset contains Mammal occurrence records (2015-18) in the Valparai Plateau and Anamalai Tiger Reserve, Western Ghats, India. It includes a few occurrence records of other chordates. Occurrence records were gathered in the field by researchers of the Nature Conservation Foundation, India, using a mobile data collection application. Suggested citation is:
Nature Conservation Foundation (2022). Mammal occurrence records (2015-18) in the Valparai Plateau and Anamalai Tiger Reserve, Western Ghats, India. Nature Conservation Foundation, India. Dataset, Zenodo. DOI: 10.5281/zenodo.7008315

Besides this 000_README.txt file, the dataset includes 326 images (photographs) and three comma-delimited text (csv) files as explained below:
1) 001_valparai_mammals.csv -- raw data file from the mobile app (columns are self-explanatory)
2) 002_valparai_mammals.csv  -- raw data file of linked images from the mobile app (columns are self-explanatory)
3) 003_mammal_occurrence_zenodo_2015-18.csv -- curated and compiled dataset with the following columns: 

observation_id: unique id given to a record (corresponds to fulcrum_id in raw data set) observation
latitude: latitude in decimal degrees N (WGS 84 datum)
longitude: longitude in decimal degrees E (WGS 84 datum)
date_: date of observation
time: time of observation
place: locality name
type_of_observation: type of observation indicating whether it was sighting, sign (based on Vocalisation/call, track/pugmark, scat/dung), death, electrocution, roadkill
notes: general notes and remarks including number of individuals where available
photo: reference id of corresponding photograph (as in the jpg filename) 
gps_altitude: altitude in metres estimated by the phone GPS
gps_horizontal_accuracy: horizontal accuracy in metres estimated by the phone GPS (set at 500 m in a few cases where GPS location was assigned based on locality name)
verbatimIdentification: taxon name as noted originally
scientificName: scientific name (or Family in a few cases)
vernacularName: common or English name
recordedBy: names of observers (separated by | )
georeferenceRemarks: remarks on georeference
occurrenceID: unique occurrence ID assigned to each taxon (recorded under an observation_id)
